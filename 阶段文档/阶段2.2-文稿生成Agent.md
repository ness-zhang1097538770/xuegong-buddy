## 三、新增数据模型

### templates

| 字段 | 类型 | 说明 |
|---|---|---|
| id | INTEGER PK | |
| name | VARCHAR(100) | 模板名称（如"谈心谈话记录"） |
| category | VARCHAR(50) | 分类：谈话记录/班会方案/评优/总结/简报/通知/其他 |
| description | TEXT | 模板用途说明 |
| style | VARCHAR(30) | 文风：formal（正式上报）/soft（谈心柔和）/brief（简洁简报） |
| system_prompt | TEXT | 系统提示词 |
| user_prompt_template | TEXT | 用户提示词模板，含 {变量} 占位 |
| variables | TEXT | JSON 数组，如 ["student_name","class_name","date"] |
| is_builtin | BOOLEAN | 是否为内置模板（内置不可删除） |
| creator_id | INTEGER FK→users | 创建者（内置模板为 NULL） |
| created_at | DATETIME | |

## 四、API 设计

### 4.1 模板管理

#### GET /api/v1/templates
- 需要认证
- 查询参数：`?category=谈话记录&style=formal`
- 响应：`{"templates": [...], "total": 10}`

#### GET /api/v1/templates/{id}
- 需要认证
- 响应：单个模板详情（含 system_prompt 等完整字段）

#### POST /api/v1/templates
- 需要认证
- 请求：`{"name":"...","category":"...","system_prompt":"...","user_prompt_template":"...","variables":["..."],"style":"formal"}`
- 响应 201：创建的模板

#### PUT /api/v1/templates/{id}
- 需要认证，只能修改自己的模板，内置模板不可修改
- 响应：更新后的模板

#### DELETE /api/v1/templates/{id}
- 需要认证，只能删除自己的模板，内置模板不可删除

### 4.2 文稿生成

#### POST /api/v1/doc/generate
- 需要认证
- 请求：
```json
{
  "template_id": 1,
  "variables": {
    "student_name": "张三",
    "class_name": "计算机2024级",
    "date": "2026-09-20"
  },
  "style": "formal"
}
```
- 响应 201：
```json
{
  "task_id": 1,
  "status": "done",
  "content": "谈心谈话记录\n\n谈话对象：张三\n班级：计算机2024级\n日期：2026-09-20\n\n...",
  "docx_url": "/api/v1/doc/download/1"
}
```

#### GET /api/v1/doc/download/{task_id}
- 需要认证
- 响应：.docx 文件流（Content-Disposition: attachment）

#### GET /api/v1/doc/tasks
- 需要认证
- 响应：最近生成任务列表

## 六、Prompt 设计

```python
DOC_GENERATE_SYSTEM = """你是一位高校学工领域的专业文书撰写助手，名叫"学工Buddy"。
请根据用户提供的模板格式和填写信息，生成规范的学工文书。"""

DOC_GENERATE_USER = """## 模板：{template_name}
## 分类：{category}
## 文风要求：{style_desc}

## 填写信息
{fill_info}

## 模板格式
{template_content}

请严格按上述格式生成文书，变量用填写信息替换，不添加模板中没有的章节。"""
```

## 九、风险

| 风险 | 应对 |
|---|---|
| Word 导出中文乱码 | python-docx 原生支持中文，已验证 |
| 模板变量替换遗漏 | 生成前校验：所有变量必须已填写 |
| 模型生成格式不稳定 | Prompt 给正反例 + 宽容解析 |
