# 前端技术适配声明｜学工 Buddy

> 基于《AI Agent 产品 Vibe Coding 通用前端技术栈手册》、后端 MVP 代码、PRD
> 生成日期：2026-09-20

## 1. 项目判断

- **产品类型**：垂直场景 AI 办公 SaaS（高校辅导员助手）
- **主要用户**：一线辅导员、学工办行政干事
- **主要终端**：桌面 Web 为主，兼顾移动端基本可用
- **新项目或已有项目**：新项目（后端已有 FastAPI，前端从零搭建 Next.js）
- **本阶段业务目标**：将临时 HTML 验收页升级为正式前端，覆盖知识库问答、文稿生成、台账处理、常用网站四大模块，保持后端 API 不变

## 2. 输入资料

- **PRD**：已读取（两版 PRD）
- **后端手册**：已读取并完成阶段 2 MVP
- **接口文档**：完整（FastAPI 自动生成的 /docs + 已有证据）
- **设计稿**：无（产品经理选择"C. 我来定"——按中性专业风格先做代表页）
- **现有代码**：后端 FastAPI + 临时 chat.html（功能可运行）

## 3. 技术选择

| 项 | 选型 | 说明 |
|---|------|------|
| 框架与版本 | Next.js 16 + React 19 | 手册默认方案，稳定生态 |
| 语言 | TypeScript strict | 手册 A 层强制要求 |
| 样式 | Tailwind CSS 4 + CSS 变量 | 统一设计 token，与临时页风格延续 |
| 图标 | Lucide | 手册默认，简洁统一 |
| 数据请求 | 集中式 API 客户端 + fetch | 不需 TanStack Query（暂无跨页缓存需求） |
| 流式通信 | Fetch Streaming（SSE） | 知识库问答流式输出 |
| 表单 | React Hook Form + Zod | 文稿生成多变量表单、台账行数配置 |
| 状态管理 | React 内置（useState/useReducer） + URL params | 单页工作台，无需全局 store |
| 组件库 | shadcn/ui（基于 Radix） | 对话框、下拉菜单较多，无障碍基础好 |
| 测试 | Vitest + React Testing Library | 手册默认 |
| E2E | Playwright（阶段 3.4 引入） | 核心闭环覆盖 |

## 4. Agent 状态

| 后端状态 | 前端映射 | 表现 |
|---------|---------|------|
| `generating` | `running` | 按钮禁用 + 进度提示 |
| `done` | `succeeded` | 展示结果 + 下载按钮 |
| `failed` | `failed` | 错误信息 + 重试按钮 |
| SSE chunk | `streaming` | 增量文本渲染 |
| SSE done/error | `succeeded`/`failed` | 关闭流、展示最终结果 |

- **等待用户确认**：文稿/台账预览后弹窗确认下载（已实现）
- **取消/重试**：生成中可取消请求（前端 abort）；失败后可重试
- **断线恢复**：通过任务 ID 轮询后端状态（文稿有 task 记录）

## 5. 页面与产物

### 核心页面

| 路由 | 页面 | 对应后端模块 |
|------|------|------------|
| `/` | 知识库问答（首页） | KB RAG |
| `/doc` | 文稿生成 | 文稿 Agent |
| `/excel` | 台账处理 | 表格 Agent |
| `/sites` | 常用网站 | 静态数据 |
| `/login` | 登录/注册 | Auth |

### 共享布局

- 左侧导航栏（桌面端展开，移动端抽屉）
- 顶部用户信息 + 退出

### 核心业务闭环

```
登录 → 上传知识库文档 → 流式问答 → 看到引用来源
     → 选择模板+填变量+上传参考文件 → AI生成文稿 → 预览确认 → 下载 Word
     → 上传 Excel → 批量生成评语 → 预览确认 → 下载 Excel
     → 浏览常用网站导航
```

### 产物类型

- 文本：知识库问答（流式）、文稿（Markdown → Word）
- 文件：Word 下载、Excel 下载
- 链接：常用网站（新标签页打开）

### 响应式目标

- 桌面：1280px+（侧栏展开）
- 平板：768px（侧栏折叠）
- 手机：390px（底部导航 + 抽屉）

## 6. 偏离本手册的地方

| 偏离项 | 原因 | 影响 |
|--------|------|------|
| 无独立前端部署（先本地联调） | 阶段 3 专注前端开发，部署在阶段 4 统一做 | 不影响功能验证 |
| 暂不引入 TanStack Query | 无跨页数据共享需求 | 代码更简单，后续按需加 |
| 知识库 RAG 问答保持 SSE | 后端已实现 Fetch Streaming | 无需改为 WebSocket |
| 无 PWA/i18n | MVP 不需要 | 不影响交付 |
