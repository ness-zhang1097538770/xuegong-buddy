# 阶段 3 正式前端开发文档｜学工 Buddy

> 日期：2026-09-20
> 范围：将临时 HTML 验收页升级为 Next.js 正式前端，覆盖全部四大功能模块

## 1. 本阶段目标

辅导员打开浏览器 → 登录 → 在一个统一的界面中完成：知识库问答、文稿生成、台账处理、浏览常用网站。桌面端为主要使用场景，手机端基本可用。

## 2. 范围

### 本阶段包含

| 页面/模块 | 功能 |
|-----------|------|
| `/login` 登录注册 | 邮箱+密码登录，邀请码注册，登录态持久化 |
| `/` 知识库问答 | 文档上传、列表管理、流式问答（SSE）+引用 |
| `/doc` 文稿生成 | 模板选择、变量填写、参考文件上传、生成+预览+下载 Word |
| `/excel` 台账处理 | Excel 上传预览、批量生成评语、预览确认+下载 |
| `/sites` 常用网站 | 4 类 12 站点卡片导航 |
| 共享布局 | 左侧导航栏、顶部用户区、全局免责声明 |

### 本阶段不包含

- 新闻聚合功能（新 PRD 第二项，后续做）
- 移动端原生 App
- 上线部署（阶段 4）
- 自定义模板管理 UI（MVP 用内置模板）
- 管理后台（邀请码管理暂保持后端 API 即可）

## 3. 用户流程

```
进入 /login → 登录/注册
  → 进入 /（知识库问答首页）
  → 左侧导航切换模块：
      💬 问答：上传文档 → 输入问题 → 流式看到回答+引用
      📝 文稿：选模板 → 填变量 → 上传参考文件 → 生成 → 预览 → 下载 Word
      📊 台账：上传 Excel → 预览 → 生成评语 → 预览 → 下载 Excel
      🔗 网站：浏览 12 个站点卡片，点击直达
```

## 4. 页面状态矩阵

| 模块 | 初始 | 加载 | 空 | 运行 | 流式 | 成功 | 失败 | 恢复 |
|------|------|------|---|------|------|------|------|------|
| 知识库问答 | 文档列表 + 输入框 | 文档列表加载中 | "暂无文档" | 等待回答 | 增量文本 | 回答+引用 | 错误提示 | 刷新恢复列表 |
| 文稿生成 | 模板下拉+变量表单 | 模板列表加载中 | 无模板时报错 | "生成中..." | — | 预览+下载 | 错误+重试 | 历史任务列表 |
| 台账处理 | 文件选择器 | — | "请上传 Excel" | "生成中..." | — | 预览表格+下载 | 错误提示 | 重新上传 |
| 常用网站 | 分类卡片 | 数据加载中 | "加载失败" | — | — | 正常展示 | — | — |

## 5. 接口契约

沿用后端已有 API（`/api/v1/*`），通过 Next.js rewrites 同源代理。

| 前端代理路径 | 后端实际地址 |
|-------------|-------------|
| `/api/*` | `http://127.0.0.1:8000/api/*` |

鉴权：Cookie 方案（后端签发 JWT → Set-Cookie HttpOnly），前端不自行管理 token。

## 6. 实现方案

### 路由结构

```
app/
├── layout.tsx              # 根布局（字体 + 全局 CSS）
├── (auth)/
│   ├── layout.tsx          # 无导航的登录布局
│   └── login/
│       └── page.tsx        # 登录/注册页
├── (workspace)/
│   ├── layout.tsx          # 左侧导航 + 顶栏
│   ├── page.tsx            # 知识库问答（首页）
│   ├── doc/
│   │   └── page.tsx        # 文稿生成
│   ├── excel/
│   │   └── page.tsx        # 台账处理
│   └── sites/
│       └── page.tsx        # 常用网站
├── api/
│   └── [[...path]]/
│       └── route.ts        # 同源代理转发
└── error.tsx / loading.tsx # 全局错误/加载页
```

### 组件结构

```
components/
├── ui/                     # Button, Input, Card, Dialog, Select, FileUpload 等
├── layout/
│   ├── sidebar.tsx         # 左侧导航
│   └── header.tsx          # 顶栏
└── features/
    ├── chat/               # 知识库问答组件
    ├── doc-gen/            # 文稿生成组件
    ├── ledger/             # 台账处理组件
    └── sites/              # 常用网站组件
```

### 设计系统（中性专业风格）

| Token | 值 | 用途 |
|-------|----|------|
| `--primary` | `#2563eb` | 主按钮、链接、选中态 |
| `--bg` | `#f8fafc` | 页面背景 |
| `--surface` | `#ffffff` | 卡片/面板背景 |
| `--text` | `#1e293b` | 正文 |
| `--muted` | `#64748b` | 次要文字 |
| `--border` | `#e2e8f0` | 边框/分隔线 |
| `--danger` | `#ef4444` | 错误/删除 |
| `--success` | `#22c55e` | 成功状态 |
| `--radius` | `8px/12px` | 按钮/卡片圆角 |
| `font` | Inter + PingFang SC | 西文+中文 |
