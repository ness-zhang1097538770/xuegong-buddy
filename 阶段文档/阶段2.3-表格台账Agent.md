# 阶段 2.3：表格/台账 Agent 技术开发文档

> 日期：2026-09-20
> 范围：模块 3——表格/台账 Agent（Excel 上传 → 批量 AI 生成 → 预览确认 → 下载）

## 1. 功能概述

辅导员上传学生信息 Excel，系统逐行调用大模型生成个性化评语，用户预览确认后下载带评语的完整 Excel。

### 核心流程
```
上传 Excel → 预览原始数据 → 批量 AI 生成评语 → 预览评语表格 → 确认并下载
```

## 2. 技术方案

| 组件 | 选型 | 说明 |
|------|------|------|
| Excel 解析/写入 | openpyxl | 纯 Python，无外部依赖 |
| 模型调用 | 通义千问 qwen-plus | 并发生成，ledger_concurrency=6 |
| 并发策略 | ThreadPoolExecutor | 每行独立调用，互不影响；单行最多重试 2 次 |
| 结果持久化 | 本地磁盘 data/results/ | 服务重启不丢失，避免内存缓存失效 |
| 下载 | FastAPI FileResponse | 支持断点续传（浏览器自动） |

## 3. API 设计

| 端点 | 方法 | 说明 |
|------|------|------|
| `/api/v1/excel/upload/read` | POST | 上传 Excel，返回预览（前10行）|
| `/api/v1/excel/batch-generate` | POST | 批量生成评语，返回预览数据+下载链接 |
| `/api/v1/excel/download/{id}` | GET | 下载结果 Excel（磁盘持久化）|
| `/api/v1/excel/extract` | POST | 从自由文本提取信息到台账字段 |

### 批量生成响应（v2.3 新增字段）

```json
{
  "task_id": "xxx",
  "row_count": 3,
  "download_url": "/api/v1/excel/download/xxx",
  "headers": ["姓名","班级","学业表现","活动参与","备注","AI评语"],
  "preview": [{"姓名":"张三","AI评语":"该生表现优秀..."}]
}
```

## 4. 前端交互演进

| 版本 | 流程 | 问题 |
|------|------|------|
| v1（初始）| 上传→生成→直接下载 | 无法预览评语，需下载后再查看 |
| v2（当前）| 上传→生成→**预览表格**→确认下载 | 用户可审核后再决定是否下载 |

## 5. 关键决策

| 决策 | 结论 |
|------|------|
| 评语字数 | 150-200 字 |
| 风格 | 肯定优点 + 温和指出改进方向 + 关心语气 |
| 单行最大重试 | 2 次，间隔 1.5s |
| 并发数 | 6（可配置）|
| 结果持久化 | 磁盘 data/results/，不依赖内存 |
