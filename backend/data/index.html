05 · 下一步

落地建议

这套稿子可以直接交给前端还原，也可以先拿去和辅导员做一次可用性走查。几个建议先定的事情：

① 先把 tokens 落地成 CSS 变量

本稿所有颜色都来自 styles.css 里的 :root 变量。前端接入时直接复用，后续换主题（比如开学季换暖色）只改一处。

② 建立图标与插画规范

统一 2px 描边、24px 网格、圆头圆角。空状态建议做一组「校园生活」插画（宿舍、图书馆、操场），比通用插画更有归属感。

③ 关键路径做一次真人走查

找 2–3 位一线辅导员，用真实数据跑「审批一张假条」「录入一次谈话」「查一次寝」三个任务，记录卡点再改，比评审会更有效。

④ 深色模式优先级

查寝场景多在夜间使用，建议移动端单独提供深色模式；PC 端可延后。
