# 学工Buddy · 辅导员 AI 副驾

> 个人副驾 Copilot：不替辅导员做决定，只替辅导员**记、写、提醒**。
> AI 输出仅为草稿，涉及学生评价、思政与危机材料必须人工复核。

当前进度：V0.3-A 四页面（副驾首页 / 谈话记录仪 / 一人一页 / 通知变材料）前端已完成，专家智能体页已补；V0.1 内容生产（知识库问答 / 文稿生成 / 台账处理 / 常用网站）保留。

## 一、启动方式

前置：Python 3.13、Node.js 22、npm 10，后端虚拟环境已就绪（`backend/.venv`）。

```bash
# 1) 启动后端（FastAPI，端口 8000）
cd backend
.venv/bin/python -m uvicorn app.main:app --host 127.0.0.1 --port 8000

# 2) 启动前端（Next.js，端口 3000，另开一个终端）
cd frontend
npm install          # 首次
npm run dev
```

打开 http://127.0.0.1:3000

## 三、验证方法（照着点）

1. **副驾首页 `/`**：顶部应看到身份 + 周期下拉 + 4 个数字（待我审批 / 待跟进谈话 / 今日异常宿舍 / 学业预警人数），下面「待办清单」每条可点「标记完成」内联处理；右上角「新增」可手动加一条提醒（标题 + 时间 + 备注）。
2. **谈话记录仪 `/talks`**：右侧选学生 → 填「本次要点」→「生成 AI 初稿」（出现「草稿」水印）→「采纳到表单」→ 人工修改 →「保存并归档」；保存后去该生「一人一页」能看到这条时间轴；也可点「导入录音（转文字）」上传一段录音，自动转文字并生成初稿。
3. **一人一页 `/students`**：列表点任意学生打开抽屉，看「学业与考勤 + 叙事时间轴」，可「导出交接包」Word。
4. **通知变材料 `/notice`**：填一句话主题 →「生成全套材料」（约 20–30 秒）→ 六个标签页预览三版通知 + 班会方案 + 签到表 + 纪要模板，可「下载 Word」；左侧「签到表（导入名单生成）」可上传班级名单 Excel（含姓名列），直接生成带真实姓名的签到表并可导出 Word。
5. **专家智能体 `/experts`**：5 位辅导员专家（谈心谈话教练/心理危机应对顾问/笔杆子/资助与评奖专员/学业预警助手），选专家 → 点示例问题或直接提问 → 流式对话，会话自动保存可回看。

## 四、自动检查

```bash
npm run build       # 生产构建
```
