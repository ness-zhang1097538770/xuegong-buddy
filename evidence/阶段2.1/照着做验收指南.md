# 阶段 2.1 验收指南——照着做

## 前提
- 已填写 `.env` 中的 `DASHSCOPE_API_KEY`
- 终端在 `docs/办公产品/backend/` 目录

## 一、运行 mock 测试（不需要 Key）

```bash
cd docs/办公产品/backend
.venv/bin/python -m pytest tests/ -v
```
预期：26 个测试全部显示绿色 PASSED

## 二、启动服务并验收

### 1. 启动
```bash
.venv/bin/uvicorn app.main:app --host 127.0.0.1 --port 8000
```

### 2. 打开验收页面
浏览器访问 **http://localhost:8000**

### 3. 注册账号
- 先需要邀请码。用 curl 生成（管理员初始引导）：
```bash
# 先直接通过数据库创建种子数据：
.venv/bin/python -c "
from app.models.base import init_db, SessionLocal
from app.models.invite_code import InviteCode
init_db()
db = SessionLocal()
db.add(InviteCode(code='DEMO01'))
db.commit()
db.close()
"
```
- 在页面点击"注册"，输入邮箱、密码 ≥6 位、邀请码 `DEMO01`
- 注册成功后切到"登录"登录

### 4. 上传文档
- 在"知识库文档"区域选择一个 .txt 或 .pdf 文件上传
- 看到"已完成"状态

### 5. 流式问答
- 在对话框输入问题（如"一等奖学金多少钱"）
- 观察流式输出逐字显示
- 回答末尾有引用来源

### 6. 边界测试
- 问一个文档中不存在的问题（如"食堂几点开饭"）
- AI 应回复"暂未找到相关信息"
