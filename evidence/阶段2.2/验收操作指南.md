# 阶段 2.2 验收操作指南（产品经理照着做）

## 前提
- 后端服务已启动（运行 `cd backend && source .venv/bin/activate && python -m app.main`）
- 浏览器打开 `http://localhost:8000`

## 一、检查内置模板

1. 打开 http://localhost:8000，登录（如果没有账号，先注册）
2. 点击「📝 文稿生成」标签
3. 点击「选择模板」下拉框
4. ✅ 看到 **10 个内置模板**：谈心谈话记录、主题班会方案、团日活动方案、评优推荐意见、困难生认定材料、月度工作总结、学期工作简报、突发事件情况报告、通知公告、学生综合评语

## 二、生成一篇文稿

1. 在文稿生成标签页，选择「谈心谈话记录」
2. 页面自动显示 6 个填写框：student_name、class_name、date、location、topic、background
3. 填入任意测试内容，如：
   - student_name: 张三
   - class_name: 计算机2024级
   - date: 2026-09-20
   - location: 辅导员办公室
   - topic: 学业规划咨询
   - background: 张三对未来方向迷茫，主动预约
4. 文风选「谈心柔和」
5. 点击「生成文稿」
6. ✅ 等待约 10-15 秒，文稿内容出现在下方预览区
7. ✅ 内容包含：一、谈话背景与目的 / 二、学生陈述要点 / 三、辅导员反馈与建议 / 四、后续跟进计划

## 三、下载 Word 文件

1. 文稿生成后，点击「📥 下载 Word」
2. ✅ 浏览器下载一个 .docx 文件
3. ✅ 用 Microsoft Word 或 WPS 打开
4. ✅ 格式正确：标题居中、章节标题加粗、末尾有免责声明「⚠️ 本文件由 AI 生成，仅为草稿...」

## 四、测试不同文风

1. 选择「通知公告」模板，文风选「正式上报」，填入内容，点生成
2. ✅ 生成内容措辞规范、格式正式
3. 再选「谈心谈话记录」，文风选「谈心柔和」，生成
4. ✅ 明显不同：语气温和、体现关心
